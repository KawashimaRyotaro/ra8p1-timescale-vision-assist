# 開発順序

この順序は固定仕様ではありません。評価結果に応じて変更します。

## 現在地

```text
実機確認済みデフォルト        完了
独立評価方式の導入            完了
カメラから液晶までの基本経路  確認済み
カメラと液晶の色経路          実施中
```

## カメラ表示の評価結果

Renesas公式例を利用して、次の基本経路を実機で確認しました。

```text
OV5640 → MIPI CSI-2 → VIN → 外部SDRAM → GLCDC → LCD
```

この結果は経路全体の動作確認です。外部SDRAM、各画像バッファ、処理時間、
画像欠落、表示遅延は個別に測定できていません。

## 次の評価順序

一度に追加する要因を限定します。

1. カラーバーでカメラ側とLCD側の色経路を分離する
2. OV5640のAECとAGCを自動にし、白飛びと黒つぶれを評価する
3. OV5640のAWBを評価し、黄色みを調整する
4. 3枚の画像バッファの切替動作を確認する
5. フレームレート、画像欠落、表示遅延を測定する
6. μT-Kernelタスクへカメラ取得完了通知を移植する

## 統合システムの候補順序

1. リアルタイム処理の基盤
2. カメラ入力
3. 時間変化の解析
4. AI（Artificial Intelligence：人工知能）推論
5. 緊急処理と詳細処理の優先順位評価
6. 出力機能
7. 測定結果に基づく最適化

## 完了条件

各評価は次を記録して終了します。

- 何を確認したか
- 成功したこと
- 失敗したこと
- 測定値
- 学んだこと
- 最終設計へ反映するか

独立評価プロジェクトは途中で動かない状態を許容します。ただし、
`firmware/ra8p1/`と`main`ブランチの既知動作状態は保護します。
